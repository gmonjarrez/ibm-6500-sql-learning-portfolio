Case 31: Measurement Model Assessment

AuthorGeorgia Monjarrez
DateNovember 25, 2026

1 Purpose and case context

This CFA tests whether Case 31 responses support two related factors: employee proficiency and operational effectiveness. Members can rate staff highly while having concerns about statements or loans.

2 Constructs and indicators

Factor Fields in the SPSS file Response scale used
Employee proficiencies q3 courtesy, q4 helpfulness, q5 professionalism, q6 availability 1–5, strongly disagree to strongly agree
Operational effectiveness q9_r statement frequency 1–5, never to too often after reversal
Operational effectiveness q10_r statement accuracy 1–4, poor to excellent after reversal
Operational effectiveness q11 statement clarity, q12 account confidentiality Original coding is 1 = yes, 2 = no. Analysis coding is 1 = no, 2 = yes.
Operational effectiveness q31 financial information confidentiality, q32 processing speed, q33 whether services meet needs, q34 application ease 1–5, strongly disagree to strongly agree

Q38 groups respondents by headquarters residence (R4a–c). Q7 describes savings-rate opinions (R1), and Q28, the borrowing screener, is absent from the data. Q13r–Q26r measure service awareness (R4b, R5), with Q13r predicting Q33 in H1. Q8r and Q30 are the paired loan-rate measures (H2), and Q37r rates overall management (R4c, R6). These single-item measures remain observed because their measurement error cannot be estimated without extra constraints. Q33 also serves as an operational indicator.

4 Hypothesized model and estimation

Each item loads on one factor, with cross-loadings and residual correlations fixed at zero. Fixing each factor variance at 1 sets its scale. The model has 53 degrees of freedom (66 indicator correlations minus 12 loadings and one factor correlation).

WLSMV treats responses as ordered categories. The analysis uses the same 106 complete cases throughout, excluding 22 members (17.2%) with missing Q12 responses.

R code
model <- '
  Employee_Proficiencies =~ q3 + q4 + q5 + q6
  Operational_Effectiveness =~ q9_r + q10_r + q11 + q12 +
                               q31 + q32 + q33 + q34
'
complete <- x[complete.cases(x), ]
fit <- cfa(model, data = complete, ordered = items, estimator = "WLSMV",
           std.lv = TRUE, missing = "listwise")

5.1 Model fit

R code
fit_table <- function(object) {
  measures <- c("chisq.scaled", "df.scaled", "pvalue.scaled", "cfi.scaled",
                "tli.scaled", "rmsea.scaled", "rmsea.ci.lower.scaled",
                "rmsea.ci.upper.scaled", "srmr")
  values <- unname(fitMeasures(object, measures))
  rows <- c("Scaled chi-square", "df", "p", "Scaled CFI", "Scaled TLI",
            "Scaled RMSEA", "90% CI lower", "90% CI upper", "SRMR")
  printed <- formatC(values, format = "f", digits = 3)
  printed[2] <- as.character(as.integer(values[2]))
  printed[3] <- format.pval(values[3], digits = 3, eps = .001)
  data.frame(Measure = rows, Estimate = printed)
}

Fit was poor. The scaled chi-square rejected exact fit, CFI and TLI fell below .90, and RMSEA and SRMR exceeded .18. Lavaan flagged a near-perfect ordinal correlation between Q11 and Q6 and a nearly singular parameter covariance matrix. Only three members answered “no” to Q11, so its estimate is unstable.

reliability <- function(object) {
  s <- subset(standardizedSolution(object), op == "=~")
  t(vapply(split(s$est.std, s$lhs), function(lambda) {
    error <- 1 - lambda^2
    c(CR = sum(lambda)^2 / (sum(lambda)^2 + sum(error)),
      AVE = sum(lambda^2) / (sum(lambda^2) + sum(error)))
  }, numeric(2)))
}
quality <- reliability(fit)
knitr::kable(quality, digits = 3,

Employee loadings ranged from .707 to .936 (all p < .001). Helpfulness loaded strongest. CR (.916) and AVE (.734) support internal consistency and convergence.

Operations showed weaker convergence (CR = .693, AVE = .286). Q10, Q32, and Q33 loaded above .50. Q9 fell below .50, and Q12, Q31, and Q34 loaded below .40 with p > .05. Q11 loaded .947, but its SE was .396. For ordered items, CR and AVE refer to the underlying response scale.

6 Conclusion

I would hold off on structural testing. Employee proficiencies had strong loadings, while the operations items showed low shared variance and Q11 was sensitive to the estimator. Before testing structural paths, I would verify Q12’s coding and review whether statements, confidentiality, and loan processes belong in one factor.
